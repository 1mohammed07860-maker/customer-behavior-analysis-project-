# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, PostgreSQL, and Power BI.

The main objective is to understand customer purchasing patterns, spending habits, product performance, subscription behavior, and customer loyalty through data analysis and interactive dashboard visualization.

The project combines data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and Power BI dashboard development to transform raw customer data into meaningful business insights.

## 🎯 Project Objectives

- Analyze customer purchasing behavior and spending patterns.
- Compare revenue generated by male and female customers.
- Identify top-rated products based on customer reviews.
- Understand the impact of discounts on purchasing decisions.
- Analyze subscription behavior and customer loyalty.
- Segment customers based on their previous purchases.
- Explore revenue contribution across different age groups.
- Present key business insights through an interactive Power BI dashboard.

## 🔍 Project Workflow

### 1. Data Loading and Exploration
- Imported the dataset using Pandas.
- Explored the dataset using `head()`, `info()`, and `describe()`.
- Checked for missing values and inconsistencies.

### 2. Data Cleaning and Preprocessing
- Handled missing values in the Review Rating column using category-wise median imputation.
- Renamed columns using snake_case.
- Removed unnecessary columns.
- Prepared the dataset for further analysis.

### 3. Feature Engineering
Created additional features to improve analysis:

- **Age Group:** Categorized customers into different age groups.
- **Purchase Frequency Days:** Converted purchase frequency categories into numerical day values.

### 4. Database Integration
- Connected Python with PostgreSQL using SQLAlchemy.
- Loaded processed customer data into a database table named `customer`.
- Prepared the database for SQL-based analysis.

### 5. SQL Analysis

Performed 10 business-oriented SQL queries to answer questions such as:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but still spent above the average purchase amount?
3. What are the top 5 products with the highest average review ratings?
4. How do average purchase amounts differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest discount usage percentage?
7. How can customers be segmented into New, Returning, and Loyal categories?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

### 6. Power BI Dashboard

Developed an interactive Power BI dashboard to visualize customer shopping behavior and present business insights in an easy-to-understand format.

The dashboard complements the Python and SQL analysis by providing a visual representation of customer purchasing patterns and business performance.

**Dashboard file:** `Customer_Shopping_Behavior_Dashboard.pbix`

**Dashboard screenshot:** `PowerBI_Dashboard/dashboard_screenshot.png`

## 🚀 How to Run This Project

### Python Analysis

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Customer-Shopping-Behavior-Analysis.git
```

2. Navigate to the project directory:

```bash
cd Customer-Shopping-Behavior-Analysis
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Open and execute `Customer_Shopping_Behavior_Analysis.ipynb`.

### SQL Analysis

- Set up PostgreSQL.
- Configure your database connection.
- Execute the queries available in `customer_behavior_sql_queries.sql`.

### Power BI Dashboard

- Download the `.pbix` file from the `PowerBI_Dashboard` folder.
- Open it using Microsoft Power BI Desktop.
- Configure the data source if required.
- Explore the interactive dashboard.
